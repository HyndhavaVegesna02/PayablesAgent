title: Kept traces stay under Windows MAX_PATH (a shorter layout, and the long-path prefix) (PO, batch 18)
type: defect

Live ablation v2 (2026-10-04): the bare harness and four knock-outs crashed copying their first run's traces.
The destination ran past Windows' 260-character limit (a deep output folder, then traces/<harness>/<scenario
name>-run<n>/<date>/<file>).

## Acceptance Criteria
- [ ] AC1: Kept traces use a shorter layout (traces/<harness>/<scenario number>-run<n>/), the same for every
  harness.
- [ ] AC2: On Windows, the copy uses the `\?\` long-path prefix, so a deep output folder can't fail it.
- [ ] AC3: A test keeps traces under an output folder deep enough to pass 260 characters.
